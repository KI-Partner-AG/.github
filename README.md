# KI-Partner-AG/.github

Standardvorlagen der Organisation KI-Partner-AG: PR-Vorlage, Issue-Vorlagen, CONTRIBUTING und SECURITY.
GitHub verwendet diese Dateien automatisch in jedem Repository der Organisation, das keine eigene Version hat.

**Nicht hier bearbeiten.** Die Quelle liegt in `KI-Partner-AG/factory-workflows` unter `org-github/`.
Der Workflow «Org-Vorlagen synchronisieren» überträgt sie nach jedem Merge hierher und überschreibt Änderungen in diesem Repository.
